# GeoGestor v1.1.3

> **ARTEFATO HISTÓRICO — NÃO PUBLICÁVEL:** estas notas não representam a versão técnica canônica atual (`1.0.0`, apresentada como GeoGestor 1.0). Não reutilize, renomeie nem publique o instalador ou o hash de `1.1.3` como candidato vigente.

## Destaques

- Consolidação de melhorias para operação comercial, financeira, ambiental e de planejamento.
- Ampliação dos recursos de importação e associação de dados de clientes.
- Evolução das rotinas de backup, recuperação, integridade de dados e alertas operacionais.
- Melhorias de acessibilidade, navegação, relatórios e ferramentas de apoio ao trabalho técnico.

## Instalação

Baixe `GeoGestor Setup 1.1.3.exe` nos arquivos desta Release e execute o instalador no Windows de 64 bits.

## Verificações realizadas

- Verificação de tipos do web e da API.
- Testes automatizados do aplicativo desktop.
- Verificação de integridade do pacote distribuído.

## Dados locais

Esta versão não inclui bancos de dados, documentos de clientes, cópias de segurança, arquivos de ambiente ou credenciais.
