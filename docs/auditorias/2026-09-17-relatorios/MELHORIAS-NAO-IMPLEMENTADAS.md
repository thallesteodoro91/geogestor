# Melhorias não implementadas

Itens abaixo foram conscientemente mantidos fora do escopo para evitar expansão de produto ou mudança semântica:

- exportação CSV/XLSX;
- criação de novas métricas gerenciais ou novos tipos de relatório;
- persistência/versionamento de uma entidade “relatório”;
- log de auditoria para cada visualização ou exportação;
- virtualização completa das distribuições, pois os limites visuais atuais agora são transparentes;
- alteração da regra tributária ou de conversão existente;
- reparo do cenário de remoção financeira que falha fora do endpoint de relatórios;
- regeneração/assinatura do manifesto oficial de release;
- automação de NVDA/JAWS, impressão nativa, alto contraste/zoom do sistema e contenção SQLite.

Esses itens não são pré-requisito para iniciar a Sessão 12, mas os dois problemas de release/regressão devem ser resolvidos antes da próxima publicação do aplicativo.
